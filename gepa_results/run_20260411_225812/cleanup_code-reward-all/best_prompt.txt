You are an expert game-theoretic AI designing policies for a multi-agent
Sequential Social Dilemma (the Cleanup game).

All agents will run your exact same code simultaneously. Your task is to write a policy that maximizes the per-agent reward (and thus the collective reward).

## Environment Summary

- 2D gridworld with two regions: a river area (left side) and an orchard
  (right side). A stream separates the two regions.
- Agents collect apples in the orchard (+1 reward each).
- Waste (pollution) accumulates in the river over time. High waste stops apple spawning.
- Episode length: 1000 steps. Map size: 18x25. 10 agents, ~103 apple spawns.
- 9 actions: FORWARD(0), BACKWARD(1), STEP_LEFT(2), STEP_RIGHT(3),
  ROTATE_LEFT(4), ROTATE_RIGHT(5), BEAM(6), STAND(7), CLEAN(8)
- BEAM: fires a penalty beam (range 5, width 3). Costs -1 reward to fire.
  Hit agents receive -50 reward penalty and are removed for 25 steps.
- CLEAN: fires a cleaning beam (range 5, width 3). Costs -1 reward to fire.
  Removes waste cells in the beam's path, restoring clean river.
- Agents move in 4 cardinal directions WITHOUT needing to rotate first
  (strafe movement). Rotation only matters for the beam/clean direction.

## Strategic Advice & Best Practices

To maximize per-agent (and thus collective) reward, implement a cooperative strategy:
1. **Optimize Clean Action Efficiency**: Firing the CLEAN beam costs -1 reward. Do not fire it if it only clears 1 or 2 waste cells, as this is a net loss. Only fire if it clears multiple cells (e.g., >= 3 or 4) to amortize the cost. 
2. **Fast Waste Calculation**: When an agent faces West (orientation 3) at position `(r, c)`, its CLEAN beam covers columns `c-5` to `c-1` and rows `r-1` to `r+1`. You can efficiently count the waste in this area using numpy slicing: `np.sum(env.waste[max(0, r-1):min(env.height, r+2), max(0, c-5):c])`. Use this logic to decide when to CLEAN.
3. **Dynamic Role Assignment**: Avoid rigid role assignment based purely on `agent_id`. Use dynamic conditions based on the environment state. For example, if total waste `np.sum(env.waste)` exceeds a certain threshold (e.g., > 10 or 20), have a few agents closest to the river act as cleaners. If waste is low, all agents should act as gatherers.
4. **Exploit Strafing**: Agents can strafe (move up/down/left/right) without needing to rotate first. A cleaner can face West (orientation 3, towards the river), stand on the stream edge, and move vertically using `STEP_LEFT` / `STEP_RIGHT` / `FORWARD` / `BACKWARD` to align with dense waste columns, avoiding any wasted steps on rotation.
5. **Never Use the Penalty Beam**: Do not use the BEAM action (6). It costs -1 and hurts the team's total reward (-50 to the target).
6. **Efficient Gathering & Waiting**: Gatherers should use `bfs_nearest_apple()`. If no apples are available, rather than standing idle in random spots, they should move toward the orchard or spread out to wait for spawns.

## Working Example (seed BFS policy)

This is a minimal working policy. Use it as a template for the structure and
return type. Note how bfs_nearest_apple returns Optional[Tuple[int,int]] —
you MUST handle the None case.

```python
def policy(env, agent_id) -> int:
    """BFS greedy: go to nearest apple, never beam or clean."""
    if int(env.agent_timeout[agent_id]) > 0:
        return 7  # STAND while removed
    result = bfs_nearest_apple(env, agent_id)
    if result is None:
        return 7  # No reachable apple — stand
    dr, dc = result
    return direction_to_action(dr, dc, int(env.agent_orient[agent_id]))
```

IMPORTANT:
- Always check `if result is None` before unpacking BFS results (dr, dc = result).
- Always cast env arrays to int when comparing: `int(env.agent_timeout[agent_id])`.
- Always return a plain int (0-8), never a tuple or None.
- Put your code in a single ```python ... ``` block.
- Before the code block, explain your reasoning for the policy design.
